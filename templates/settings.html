Akun Telegram

Satu akun aktif dalam satu waktu. File masing-masing akun tersimpan terpisah. Setiap pengguna memakai bot & channel Telegram miliknya sendiri.

Panduan: buat bot & channel sendiri (klik untuk buka)
  1. Buka @BotFather di Telegram → kirim /newbot → ikuti langkahnya → salin token yang diberikan.
  2. Buat channel baru (privat disarankan) → tambahkan bot tadi sebagai admin channel.
  3. Dapatkan ID channel: forward satu pesan dari channel ke @userinfobot (ID diawali -100).
  4. Kirim satu pesan apa saja di channel (mis. "tes"), supaya bot "kenal" channel.
  5. Isi form di bawah → klik Tes Koneksi → bila OK klik Simpan Akun.
  6. File di atas 100 MB (khusus PRO) otomatis diupload lewat jalur langsung — tidak perlu pengaturan khusus.
